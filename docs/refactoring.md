## 本轮发现并修复的问题

代码保护过滤器收到没有可定位段落、但已标记 `code_protected` 的补丁时，会读取空对象的 `label`。已改为安全跳过并记录“未定位”，新增复现测试。

提示词文件搬迁过程中曾出现中文编码损坏；本地回归捕获后已从基线恢复，并逐项比较原有常量。仓库发布检查现在会拒绝非法 UTF-8 和替换字符，避免损坏模板进入提交。

## 回退与后续

整理前已在本机保留源码归档、分支/标签 Git bundle 和环境配置副本。备份位于忽略的 `artifacts/backups/`，包含私人配置，不能上传。备份不等于生产数据库或文件存储卷快照。

HTTP URL、任务确认协议、数据库结构和部署入口不变。大型审查调度与原生修订写回仍有必要复杂度，本轮没有将其改写成未经验证的新框架。后续优先补专用 PostgreSQL 集成环境、文档转换隔离与存储保留策略，不再堆兼容分支或增加无实际用途的抽象层。
