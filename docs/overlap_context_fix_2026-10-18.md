# 重叠补丁、跨章节上下文与预览调整

## 已核实原因

- 同轮整句补丁已把 MoCO 改成 MoCo，随后程序生成的词级补丁再次命中同一位置。
  原执行器只按引用范围判断重叠，把已经完成的同一修改误记为失败，复核据此继续误报。
- “6-way + 统一口径”的类别数核查被通用术语启发式识别为全文术语统一，送到多个无关片段。
  问题描述中的 P08/P151 等关联标签未全部解析，且上下文裁剪可能删掉目标原文。

## 修复

- 提案汇总及应用前合并相容的实际改动，保留所有来源补丁与问题 ID；拒绝项不参与。
  一个英文/数字词视为整体，不能把两个不同拼写方案组合成第三种写法。真正冲突仍明确报告。
- 数值口径不再仅因含“统一”就转为术语全篇任务；关联标签、明确章节、中文及英文摘要一起提供。
- Revision 上下文优先保证目标原文与用户约束完整，必要时超过软文本预算，调用总额度限制仍有效。
- `missing_context` 是内部调度信号，全文补齐后最多重试一次；仍未生成方案如实报告执行失败，
  不再把“摘要不在当前片段”冒充论文需要人工修改的原因。`not_applicable` 不生成兜底待办。
- 默认预览 95%，支持继续调整；右侧留出 1 cm 使原稿左移；上一页/下一页按钮上移 0.4 cm。

已保存的确认快照不自动重写，也不会重新扣次数或调用模型。新生成的方案使用修复后的逻辑。
`scripts/verify_overlap_snapshot.py` 可只读复放历史补丁，验证结果不变、重复冲突消失和关联原文到位。
