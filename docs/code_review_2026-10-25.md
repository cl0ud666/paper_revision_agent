## 验证范围

本地验证结果：后端 **491 passed、1 skipped、23 subtests passed**；Ruff 检查通过，66 个 Python 文件格式校验通过；前端格式校验、TypeScript/Vite 生产构建通过；使用模拟接口的页面测试 **5 passed**。`git diff --check` 通过。

页面测试覆盖简单注册、机会耗尽、仅人工事项确认、选项 B 的原值提交、完成页文案。它们不调用真实模型，也不等于真实论文全流程或生产负载测试。

敏感信息检查器扫描当前待发布文件以及 HEAD、分支和标签可达历史；本次结果为零发现。这是启发式检查，不保证排除了所有个人信息或密钥。本地编辑器恢复引用不属于发布分支，也不应镜像推送。

## 保留的边界和后续工作

- 真实 PostgreSQL 集成测试需要 `PRA_TEST_POSTGRES_URL`，本轮未配置；不能把 SQLite 测试通过等同于生产数据库验证。
- 本轮没有调用付费模型验证论文修改质量，没有更新生产服务器，也没有推送 GitHub。GitHub Actions 首次云端运行仍需检查。
- DOCX 修订写回、审查调度和预览仍较复杂；本轮优先拆分职责清晰的部分，没有为缩短文件强拆依赖紧密的编辑逻辑。
- Python 依赖仍混用固定版本和版本范围，尚未提供完整跨平台锁文件。
- 面向公众的高负载、文档转换进程隔离、存储保留及备份恢复演练，需要独立验证，不能由单元测试代替。
- 未替项目所有者选择开源许可证；若允许他人自由复用，应补充 LICENSE。
